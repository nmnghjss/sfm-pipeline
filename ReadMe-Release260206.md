# 程序说明

## 输入输出
输入: 一组图像，需要放置在 input 目录下

输出：sfm稀疏重建结果, 包括相机内参，位姿以及稀疏点云

## 命令行用法

### 基础用法

```bash
run-sfm.exe -s data_dir [-o output_dir] [--default]
```

参数说明
-s: 指定输入数据目录，即为包含图像 input 文件夹的 目录
-o: 指定输出目录，可以不指定，若不指定，则为 -s 目录。当输出目录为-s指定的输入数据目录时，执行结束之后目录结构如下
![alt text](image.png)

--default：用于指定colmap稀疏重建算法的选项，不指定时为优化模式；使用该选项时稀疏重建将采样colmap的默认增量式模式，效率较低

## 注
底层依赖为 colmap-3.13.0，支持 中文路径
